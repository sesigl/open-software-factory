# tools

The repository tooling: the deterministic checks from [`docs/quality/checks.md`](../docs/quality/checks.md) and
the helpers behind `make`. From phase 2 on, the released `spec-trace` module replaces TRACE, STEPS and PASS.

## Quick start

```sh
make install     # pnpm dependencies and the pinned lychee and oasdiff binaries
make check       # lint and the static checks, in seconds
make verify      # everything: lint, types, all system tests, all checks
```

## Commands

`make` calls `osf`; run it directly with `node tools/bin/osf.ts <command>` from the repository root.

| Command | Make target | What it does |
| --- | --- | --- |
| `osf check [ID ...]` | `make check` | Run the named checks. No ID runs the fast set: SPEC, TRACE, STEPS, NOSKIP, ASSERT, BOUNDARY-STATIC, BOUNDARY-ENV, ISOLATION, DOCS-GEN, DOCS-LINKS, ADR. |
| `osf check --all` | `make verify` | Also PASS, FLAKE, BUDGET (they read `reports/junit/`), DOCS-AFFECTED and CONTRACT (they compare with `OSF_BASE`; CONTRACT with the last `contracts-v*` tag when there is one). |
| `osf docs-affected` | `make docs-affected` | List hand-written docs whose `covers:` paths changed since `OSF_BASE`. |
| `osf docs` | `make docs` | Regenerate every README section below a `generated by make docs` marker. |
| `osf new-module <name>` | `make new-module NAME=x` | Copy `modules/_template` and register the scenario prefix. |
| `osf next-id <module>` | `make next-id MODULE=x` | Print the next free scenario ID of a module or prefix. |
| `osf test-scenario <ID>` | `make test-scenario ID=…` | Run the one system test of a scenario. |
| `osf agents-sync` | `make agents-sync` | Link `skills/` into `.claude/skills/`, `.agents/skills/` and `.opencode/skills/`. |
| `osf install-tools` | `make install` | Download the checksum-pinned lychee and oasdiff into `.tools/bin/`. |

`make` holds no build logic (ADR 0010). `make check` runs the affected `lint`, `typecheck` and `test:system`
Turborepo tasks (`--filter=...[OSF_BASE]`) and then the fast checks. `make verify` runs those tasks for every
package without the cache, then every check. The checks themselves always run outside the Turborepo cache.

Each failure prints one line: the check ID, `file:line`, and what to fix. Each check ends with `ID ok` or
`ID failed: N`. The exit code is 1 when any check failed.

## Configuration

| Variable | Meaning |
| --- | --- |
| `OSF_BASE` | Git ref to compare with for DOCS-AFFECTED, CONTRACT (only without a `contracts-v*` tag in HEAD's history) and the dependency rule of ADR. `make` uses the merge base with `origin/main`. Without it, these comparisons print `skipped` and `osf check --all` (so `make verify`) fails. |
| `OSF_PR_BODY` | File with the pull request description. DOCS-AFFECTED accepts `docs-reviewed: <path>` lines in it. CI passes the description of the pull request, and for a push to `main` the description of the merged pull request. |
| `OSF_JUNIT_DIR` | Folder with JUnit XML results. Default `reports/junit`. |
