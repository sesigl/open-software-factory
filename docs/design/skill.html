Triage a Linear issue
Use this skill when a work item's origin is a Linear issue.
Steps
  1. Read the issue with scripts/issue.sh.
  2. Search for open issues with the same error text. Link a duplicate and stop.
  3. Set the team from the table in teams.md.
  4. Set the priority and say why in one sentence.
Do not
Close an issue, or change one that a person is assigned to.
