# ui

The design system of the open software factory's UI, "precise industrial" (`docs/design/`): tokens as CSS custom
properties for a dark and a light theme, the brand, and the components of the console's pages. Dark is the default;
the light theme is `data-theme="light"` on the root element, which the server sets from a cookie, so a page renders
in its theme without script. Decisions: [ADR 0133](../../docs/decisions/0133-design-system.md).

## Quick start

```ts
import { files, text } from "@opensoftware/ui";

// Serve the tokens and the favicon from your own origin; the pages link them.
const tokens = text("tokens"); // the CSS; files.tokens is its path
const favicon = text("favicon");
```

```css
body {
  background: var(--osf-bg-ground);
  color: var(--osf-text);
  font: var(--osf-size-text) / 1.5 var(--osf-font-sans);
}
```

## Tokens

| Group | Names |
| --- | --- |
| Backgrounds | `--osf-bg-ground`, `--osf-bg-surface`, `--osf-bg-raised` |
| Lines | `--osf-line`, `--osf-line-strong` |
| Text | `--osf-text`, `--osf-text-muted`, `--osf-text-subtle` |
| Signal | `--osf-signal` (the main action, work that waits for a person), `--osf-on-signal` (text on it) |
| States | `--osf-state-running`, `--osf-state-waiting`, `--osf-state-failed`, `--osf-state-complete`, `--osf-state-cancelled` |
| Type | `--osf-font-sans`, `--osf-font-mono`, `--osf-size-title`, `--osf-size-section`, `--osf-size-text`, `--osf-size-secondary`, `--osf-size-label`, `--osf-weight-strong` |
| Shape | `--osf-space-1` to `--osf-space-8` (a 4-pixel grid), `--osf-radius-control`, `--osf-radius-panel`, `--osf-control-height`, `--osf-navigation-width`, `--osf-motion` (none with reduced motion) |

Every text token meets WCAG 2.2 AA contrast on every background, and `--osf-on-signal` on `--osf-signal`, in both
themes; the repository's check CONTRAST proves it.

## Brand

`@opensoftware/ui/brand/icon.svg` (the icon in the current text colour), `wordmark.svg` (the icon beside "Open
Software Factory") and `favicon.svg` (the icon in the signal colour on the dark ground).

## Components

A page of the console imports them; Astro compiles them, their styles and the faces into the page's build, so a
package that uses them needs this one only while it builds (a `devDependency`):

| Component | What it is |
| --- | --- |
| `@opensoftware/ui/components/Page.astro` | The document: the title, the theme (`data-theme`), a reload after `refresh` seconds, the favicon, and `styles/base.css` with the faces, the ground, links, the focus, `.osf-action` (the main action), `.osf-alert` (a problem), `.osf-heading` (a title with its action), `.osf-tabs` (filters, in one line that scrolls on a phone), `.osf-table-panel` and `.osf-table` (a list), `.osf-cards` on a table with `.osf-card-state`, `.osf-card-corner` and `.osf-card-title` on its cells (each row a card on a phone), `.osf-dock` (the main action, fixed at the bottom of a phone's screen), `.osf-waits` (a row that waits for a person), `.osf-state .osf-state-<state>` (a state as a shape and a word) and `.osf-empty` (an empty list); for a list with its form, like the console's Secrets: `.osf-intro` (the title with what the page is for), `.osf-split` with `.osf-split-main` and `.osf-split-side` (a list beside its form, below it on a narrow screen), `.osf-list` (records as rows of a panel, `.osf-list-text` and `.osf-list-end` in a row, `.osf-missing` a row that misses something), `.osf-panel` (a form on a panel), `.osf-field`, `.osf-input`, `.osf-hint`, `.osf-buttons`, `.osf-button` (an action beside the main one, a link or a button of a form), `.osf-stack` (panels one below the other, like two forms beside a list), `.osf-footnote`, `.osf-strong`, `.osf-secondary` and `.osf-hidden` (text for a screen reader only); for a record's page, like the console's skill: `.osf-crumbs` (the way back above the title), `.osf-meta` (an exact line below it), `.osf-section` (a panel with a label in mono capitals), `.osf-needs` (what a record needs, as a row of small items) and `.osf-prose` (Markdown rendered on the server) |
| `@opensoftware/ui/components/Brand.astro` | The icon beside "Open Software Factory" |
| `@opensoftware/ui/components/Shell.astro` | The layout of a page in the new look, from `ShellData` (a type of `@opensoftware/ui`) that the page's route computes: a skip link, the navigation "Main" with the factory's name, the pages, the classic pages and the tools, the region "Account" with the person, "Sign out" and the link to the other theme, and the main content `#content`. On a phone the navigation folds behind "Menu", a `details` element, without a script |

The faces are IBM Plex Sans and Mono from the Fontsource packages, served from the page's own origin.
