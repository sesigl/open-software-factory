# ui

The design system of the open software factory's UI, "precise industrial" (`docs/design/`): tokens as CSS custom
properties for a dark and a light theme, the brand, and the components of the console's pages. Dark is the default;
the light theme is `data-theme="light"` on the root element, which the server sets from a cookie, so a page renders
in its theme without script. Decisions: [ADR 0133](../../docs/decisions/0133-design-system.md).

## Quick start

```ts
import { files, text } from "@opensoftware/ui";

// Serve the tokens and the favicon from your own origin; the pages link them.
const tokens = text("tokens"); // the CSS; files.tokens is its path
const favicon = text("favicon");
```

```css
body {
  background: var(--osf-bg-ground);
  color: var(--osf-text);
  font: var(--osf-size-text) / 1.5 var(--osf-font-sans);
}
```

## Tokens

| Group | Names |
| --- | --- |
| Backgrounds | `--osf-bg-ground`, `--osf-bg-surface`, `--osf-bg-raised` |
| Lines | `--osf-line`, `--osf-line-strong` |
| Text | `--osf-text`, `--osf-text-muted`, `--osf-text-subtle` |
| Signal | `--osf-signal` (the main action, work that waits for a person), `--osf-on-signal` (text on it) |
| States | `--osf-state-running`, `--osf-state-waiting`, `--osf-state-failed`, `--osf-state-complete`, `--osf-state-cancelled` |
| Type | `--osf-font-sans`, `--osf-font-mono`, `--osf-size-title`, `--osf-size-section`, `--osf-size-text`, `--osf-size-secondary`, `--osf-size-label`, `--osf-weight-strong` |
| Shape | `--osf-space-1` to `--osf-space-8` (a 4-pixel grid), `--osf-radius-control`, `--osf-radius-panel`, `--osf-control-height`, `--osf-navigation-width`, `--osf-motion` (none with reduced motion) |

Every text token meets WCAG 2.2 AA contrast on every background, and `--osf-on-signal` on `--osf-signal`, in both
themes; the repository's check CONTRAST proves it.

## Brand

`@opensoftware/ui/brand/icon.svg` (the icon in the current text colour), `wordmark.svg` (the icon beside "Open
Software Factory") and `favicon.svg` (the icon in the signal colour on the dark ground).
