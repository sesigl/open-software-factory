# postgres

What the modules on PostgreSQL share around [node-postgres](https://node-postgres.com): a pool that survives a lost
connection, and transactions. A library: modules depend on it, it has no command of its own and no state. Decisions:
[ADR 0039](../../docs/decisions/0039-libraries.md), [ADR 0082](../../docs/decisions/0082-postgres-library.md).

## Quick start

```ts
import { openPool, transaction } from "@opensoftware/postgres";

const pool = openPool(process.env.DATABASE_URL as string);
await transaction(pool, async (client) => {
  await client.query("INSERT INTO work (id) VALUES ($1)", ["w-1"]);
  await client.query("INSERT INTO outbox (event) VALUES ($1)", ["work.received"]);
});
await pool.end();
```

## API

- `openPool(url)` returns a `pg.Pool` with at most four clients. It listens for the errors of idle clients and of every client it
  creates. A client that loses its connection, also one that a transaction holds between two queries, then does not
  end the process: its next query fails instead.
- `transaction(pool, work)` runs `BEGIN`, `work(client)` and `COMMIT`, and returns what `work` returns. When `work`
  or `COMMIT` fails, it runs `ROLLBACK` and rejects with that error. The client goes back to the pool in every case;
  the pool destroys a client that lost its connection.

Use `pool.query(...)` for a single statement.

## Releases

release-please opens a release pull request from the Conventional Commits under `packages/postgres/`. Merging it
creates the tag `postgres-v<version>`. The workflow `.github/workflows/publish-postgres.yml` then builds `dist/` with
`pnpm build` and publishes the package to npm. The first release is `0.1.0`; until `1.0.0`, a breaking change raises
the minor version. A module that depends on the library names it with `workspace:*`; `pnpm pack` writes the released
version into the module's published `package.json`.

The one-time setup is the same as for contracts ([`contracts/README.md`](../../contracts/README.md#releases)). No
credential is stored in the repository.
