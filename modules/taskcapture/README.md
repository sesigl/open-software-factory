# taskcapture

One sentence: the one problem this module solves on its own. `make new-module` copies this working module; replace
the `hello` command with the module's first real command and keep its quick start green.

## Quick start

This quick start is scenario `SCN-TASK-001` and is tested on every change.

```sh
npx @opensoftware/taskcapture hello Ada
```

It writes `$OUTPUT/hello.txt` with the text `Hello, Ada`.

## Commands

| Command | What it does |
| --- | --- |
| `taskcapture hello <name>` | Write a greeting for `<name>` to `$OUTPUT/hello.txt`. |

## Configuration

<!-- generated by make docs from src/config.schema.json: do not edit -->

| Variable | Type | Default | Meaning |
| --- | --- | --- | --- |
| `OUTPUT` | string | `"."` | Folder of the suite, report.json and litellm-config.yaml when --suite or --out is not given. |
| `TASKCAPTURE_FORGE_URL` | string |  | Base URL of the forge API for capture. Default: https://api.github.com for github.com, <origin>/api/v3 for another GitHub host, <origin>/api/v1 for Forgejo. |
| `TASKCAPTURE_FORGE_TOKEN` | string |  | Token that may read the repository, for capture: sent to the forge API and to git clone. Without it, capture reads a public repository. Never written into a task. |
